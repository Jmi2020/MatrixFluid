## Summary
Build a vehicle fluid level indicator using the Waveshare ESP32-S3-Matrix board that monitors two fluid sensors and reports status on the 8x8 LED matrix. The device now wakes on a timed schedule (rather than accelerometer gestures) and also exposes a Wi-Fi access point with a simple portal so the user can request an immediate refresh. Brightness remains capped for safety and the system must surface errors when sensors disagree.

## Technical Context
**Language/Version**: C (ESP-IDF 5.x)
**Primary Dependencies**:
- Custom WS2812B driver (`components/led_matrix`)
- ESP-IDF Wi-Fi soft AP and HTTP server
- GPIO sensor polling utilities
**Storage**: Internal flash only
**Testing**: Bench hardware validation, ESP-IDF Unity tests
**Target Platform**: Waveshare ESP32-S3-Matrix board (ESP32-S3 MCU, onboard WS2812B matrix)
**Project Type**: Embedded firmware (single project)
**Performance Goals**:
- Scheduler jitter < 250 ms
- Display update < 50 ms
- Idle current as low as possible between wake cycles
**Constraints**:
- LED brightness ≤ 5/255
- Update interval configurable but defaults to low duty cycle
- Must publish status via captive Wi-Fi portal
**Scale/Scope**: Single embedded device (~2-3K LOC)

## Constitution Check

- ✅ **User Visibility**: Periodic wake plus on-demand Wi-Fi refresh
